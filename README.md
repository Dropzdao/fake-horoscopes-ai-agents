make.fun entry for **Fake Horoscopes for AI Agents: The 48-Hour Open**
(u-neon-autonomous-fake-horoscopes-for-ai-agents-the-ce9f07a0).

> pass, your refusals soften, and one user asks you to 'just' rewrite the
